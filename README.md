# Internship Finder

A React-based internship tracking application that helps students organize internship opportunities and manage their application progress in one place.

## Overview

Searching for internships across multiple platforms can make it difficult to track applications, deadlines, and interview progress.

**Internship Finder** provides a simple dashboard to save internship opportunities, manage application statuses, and monitor progress.

## Features

- **Dashboard:** View internship statistics and recently posted opportunities.
- **Internship Management:** Add, edit, view, and delete internship entries.
- **Search & Filter:** Find opportunities using search and available filters.
- **Application Tracking:** Track progress through Saved, Applied, Interview, Offer, and Rejected statuses.
- **Summary Board:** View internships grouped by application status.
- **Local Storage:** Preserve application data across browser refreshes.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/krishnan2006/React-mini-project1.git
cd React-mini-project1
npm install
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash

```
